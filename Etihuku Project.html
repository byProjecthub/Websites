explain browser → server flow

On-browser user requests Browser fetch page - prepare http request, like url, Browser does aDNS lookup (finding server addresses) Broswser send http request server recieves request server processes the request server talks to database server sends response back Browser renders page

Understands HTTP vs HTTPS

HTTP = HyperText Transfer Protocol, it is the standard way browsers and servers communicate. It sends web pages, form data, images, API requests, login info. HTTPS = HTTP + Security (Encryption), it uses something called ssl/tls encryption.

what a URL is

URL = Uniform Resource Locator, URL is basically the address used to find something on the internet.
